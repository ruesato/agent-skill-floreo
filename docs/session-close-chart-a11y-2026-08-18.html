    Key Decisions

    • Donut secondary segment uses --ct, not a second accent shade. --ca (#2563eb) is mid-luminance (~0.15), so any other mid-tone token (e.g. --cm) fails the 3:1 adjacent-segment test (1.48:1). Only a very dark/light color clears 3:1 against both the background and --ca; --ct resolves to near-black in light mode and near-white in dark mode, passing in both (3.38:1 / 4.95:1 adjacent).
    • Opacity is banned for data-bearing fills. A 0.5 opacity accent drops to ~2.07:1 and a 0.7 to ~2.94:1 — both below the 3:1 WCAG 1.4.11 threshold. The rules block now requires distinct tokens for segment differentiation instead.
    • Line-chart area fill exempted. The opacity=".08" <polygon> is decorative; the polyline, points, and axis labels carry the data, so it is not held to 3:1.
    • aria-labelledby references both title and desc IDs. Ensures screen readers announce the chart's name and its description without relying on the implicit <title> mapping, which is inconsistent across browsers.
    • Commit scoped to the chart-a11y hunks only. The working tree carried pre-existing unrelated modifications (see Blockers); those were excluded by temporarily reverting one entangled line, staging, then restoring it.
