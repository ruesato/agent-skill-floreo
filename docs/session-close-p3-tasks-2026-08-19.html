    Key Decisions

    • Heatmap scale — uses a 4-step discrete CSS-token scale (--cs2 → --cab → --ca → --ct) instead of opacity. Opacity encoding drops low-intensity cells below 3:1 and fails WCAG 1.4.11 for adjacent cells; discrete tokens all clear 3:1 against --cb, and --cbr borders keep same-tone neighbors separable.
    • refresh-css normalization — compresses by removing newlines and indentation only, not intra-line whitespace. Stripping all whitespace broke @media print (turned it into the invalid @mediaprint); preserving intra-line spaces keeps at-rules valid and the multi-line SKILL.md block hash-comparable to the compressed single-line doc block.
    • Two CSS end-markers — refresh-css matches both the current print-query end and the legacy v1.0 reduced-motion end, so it can patch older docs too, not just recently-generated ones.
    • macOS portability — check-floreo.sh targets bash 3.2 + BSD grep: no MAPFILE, no \b word boundaries, no pipefail with grep | wc pipelines, and -- end-of-options for patterns starting with -- (the --cab: variable-name checks).
